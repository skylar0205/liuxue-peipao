怎么拿 Token？（30秒，免费）
1. 打开 github.com → 登录或注册（邮箱即可）
2. 右上角头像 → Settings → 最下方 Developer settings
3. Personal access tokens → Tokens (classic) → Generate new token
4. Note 随便写；Expiration 选 No expiration
5. 权限只勾 gist 一项 → Generate token
6. 复制 ghp_... 那串 → 粘到上面框 → 点「开启云端同步」
